연결할 구글시트

현재 사용하는 Apps Script 웹앱 주소를 연결합니다. 웹앱 주소·조회 주기는 이 브라우저에 저장됩니다. 시트 ID를 변경해 적용하는 경우에는 연결 서버의 시트 지정도 바뀝니다.

시트 ID 변경을 적용하면 같은 Apps Script를 쓰는 다른 화면에도 적용됩니다. 서버가 기존 setSheetId 기능을 지원해야 합니다.

자동 새로고침

전체 예약·신규·처리 상태를 함께 확인할 주기를 정합니다. 일시 실패는 최대 60초 간격으로 자동 재시도합니다. 다른 탭을 보고 있거나 방금 버튼을 누른 직후에는 자동으로 건너뛰어서, 문자 발송이 새로고침에 밀리지 않습니다.

응답 대기시간 — 예약 조회와 저장 요청 모두 본문 수신까지 이 시간이 적용됩니다. 기존에 선택한 시간은 유지됩니다.

지금 상태

마지막 전체 예약 갱신 시각과 요청 상태입니다. 응답 지연은 인터넷 연결 또는 시트 서버 처리 시간의 영향을 받을 수 있습니다.
